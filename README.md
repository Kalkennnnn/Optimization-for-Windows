# PC Optimizer

Небольшая программа с графическим интерфейсом для Windows: анализирует системные параметры, влияющие на производительность (Game Mode, Game DVR, HAGS, фоновые приложения и др.), и позволяет безопасно применить рекомендуемые значения с возможностью полного отката.

## Возможности

- Сканирование параметров: текущее значение, рекомендуемое, статус
- Описание каждого параметра и его рисков
- Применение только выбранных пунктов с подтверждением
- Автоматический бэкап исходных значений и откат одной кнопкой
- Создание точки восстановления Windows
- Live-мониторинг CPU, RAM и диска
- Определение прав администратора и перезапуск с повышением прав

## Что проверяется

| Категория | Параметры |
|---|---|
| Игры | Game Mode, Game DVR, захват приложений, HAGS |
| Система | Фоновые приложения, рекомендации Windows |
| Визуал | Прозрачность, визуальные эффекты |
| Питание | Схема электропитания |
